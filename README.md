# Infantil Pedagogia

Site estático extraído do arquivo original, com HTML, CSS, JavaScript, fontes e imagens preservados.

## Executar

Use Node.js 18 ou superior e execute `npm run dev`. O servidor abre na porta 3000, ou na porta definida em `PORT`. Não há dependências externas para instalar.

`index.html`, `css/`, `fonts/`, `images/` e `js/` contêm os arquivos originais. `package.json` e `server.mjs` permitem executar o projeto em ambientes de desenvolvimento como o Google AI Studio.

A cópia estática preserva links e integrações externas presentes no arquivo original. Ela não inclui o sistema WordPress, banco de dados ou painel administrativo do site de origem.
